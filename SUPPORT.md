# Support

QuietClaw is provided on an as-is basis and there is no commercial support, service-level agreement, guaranteed response time, or maintenance commitment.

## Where to ask for help

- Use GitHub Discussions for usage questions, setup questions, and general project discussion if Discussions are enabled for this repository.
- If Discussions are not enabled, open a GitHub issue instead.
- For confirmed bugs, open a GitHub issue with a clear title, steps to reproduce, expected behavior, actual behavior, and relevant logs or screenshots.

## Before opening an issue

- Check existing issues and discussions first to avoid duplicates.
- Reduce the problem to the smallest reproducible case you can provide.
- Do not include secrets, tokens, private credentials, or sensitive message content.

## Pull requests

Pull requests are welcome for bug fixes, documentation improvements, tests, and small focused enhancements. Submitting a pull request does not guarantee review, feedback, merge, or release.

## Expectations

- Responses may be delayed or may not arrive.
- Issues and pull requests may be closed without action if they are out of scope, unclear, not reproducible, or not a fit for the project.
- If you need guaranteed support, response times, or custom work, do not rely on this repository.
